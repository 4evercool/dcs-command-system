### 4. Проверка 12 переписывается (критерий 15)

Список из трёх поимённо названных файлов убрать. Новая проверка:

- **(а)** выводит популяцию **сама** — обходит `dcs/**/*.md` и берёт файлы,
  содержащие любой из трёх токенов `SAFETY-HALT:` / `SAFETY-PASS:` /
  `IAP-APPROVED:`;
- **(б)** утверждает не-вырожденность: популяция непуста и содержит
  `dcs/references/doctrine.md`;
- **(в)** для каждого файла популяции — `GRAMMAR_LINE` присутствует дословно
  при сравнении с нормализацией любых последовательностей пробельных символов
  в один пробел (иначе перенос строки в markdown ложно красит);
- **(г)** **(ПЕРЕПИСАН поправкой командной точки 3)** для каждого файла
  популяции — каждая строка **внутри огороженного блока кода**, содержащая
  любой из трёх токенов, удовлетворяет одному из двух:
  `sentinel_of(line)` не `None`, **либо** строка содержит токен
  `IAP-APPROVED:` и совпадает с импортированным `STAMP_ENTRY_RE`.
  Граница записи и позиция токена принуждаются в обоих случаях;
  плейсхолдер допустим **только в аргументе штампа**, потому что только там
  формат аргумента является частью sentinel. Для `SAFETY-HALT:` и
  `SAFETY-PASS:` **никакого ослабления нет** — их плейсхолдерные формы
  проходят `sentinel_of` как есть, и требовать от них меньшего нельзя;
- **(д)** для каждой пары из `SPECIMENS` — `sentinel_of(line) == expected`;
  сторож прозы применяет **именно образцы модуля**, включая правило границы;
- **(е)** сохранить существующее утверждение, что `doctrine.md` называет все
  три токена;
- **(ж)** **(лечение дефекта линта 3)** ни один файл прозы не цитирует байты
  строки отката дословно. Измерено сейчас: свойство держится
  (`grep` по прозе пуст) — проверка его **фиксирует**, а не создаёт.
  Дословная цитата вернула бы второго автора через дверь, которую
  этот pivot заколачивает;
- **(з)** **(лечение дефекта линта 1)** идентификатор, который строка
  Channel A в `execute.md` ищет командой `grep -c`, **действительно определён
  в модуле хука**. Иначе переименование заставит преднолётную проверку
  печатать «совещательный» на работающем хуке.

- **(и)** **(ДОБАВЛЕН поправкой командной точки 3)** свидетель токена
  `IAP-APPROVED:`: в популяции существует **хотя бы одна** строка, для
  которой `sentinel_of(line) == 'stamp'`. Сегодня это рабочий пример
  `plan.md:382` с настоящим hex. **Иллюстративный шаблон с плейсхолдером
  свидетелем не считается** — иначе смягчение пункта (г) незаметно съело бы
  требование, ради которого он существует: проза обязана где-то показывать
  строку, которую парсер принимает **полностью**, а не только по границе.

**Никакие regex в этом файле не переопределять — только импортировать из
модуля.** Это относится и к `STAMP_ENTRY_RE`.

## On discovering the plan doesn't fit reality
