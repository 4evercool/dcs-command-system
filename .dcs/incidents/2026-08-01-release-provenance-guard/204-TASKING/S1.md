## Task

Build the offline provenance gate and wire it (202 criteria 1 [amended],
2, 3, 5). Create `tests/release_provenance_check.py`, patterned on
`tests/payload_check.py`'s conventions: module docstring explaining the
deliberate non-`test_` name, `argparse --repo` defaulting to the repo root
two levels up from the file, stdlib-only, no network, and this exit-code
discipline mirrored exactly (`payload_check.py:61-72`): `0` provenance
holds, `1` provenance incomplete (a real failure), `2` cannot check (a
precondition/environment problem) — `1` and `2` must never be conflated.

Let `V` = `package.json`'s version (what npm actually ships). Checks, in
order:

1. **Precondition:** `dcs/VERSION` equals `V`. If unequal, or either file
   is unreadable, exit `2`. This mechanizes `docs/publishing.md`'s
   existing "Version-sync rule (HARD)" at publish time — merge-time
   checks already enforce it at merge, but this incident exists precisely
   because publish flows bypass merge-time suites.
2. Past that precondition, exit `1` (naming which) if any of: no git tag
   `vV` exists; `git rev-parse vV^{commit}` does not equal `git rev-parse
   HEAD` (the `^{commit}` peel is load-bearing — it dereferences both
   annotated and lightweight tags); `CHANGELOG.md` has no entry for `V`.
3. Exit `0` only when the precondition and all three checks hold.

**`CHANGELOG.md`'s real heading convention is `## <version> — <date>`
with a literal U+2014 EM DASH** — verified this period at
`CHANGELOG.md:28`: `## 0.7.2 — 2026-08-01`. This is NOT ASCII `--`. Anchor
your regex to this exact convention, and anchor it so `0.7.1` can never
match a heading for `0.7.10`. Read `CHANGELOG.md` with `encoding="utf-8"`
explicitly — the platform default can mis-decode the em dash's bytes
(`E2 80 94`) and the check would then never match the real file.

Then wire `package.json`: add `"scripts.prepublishOnly": "python
tests/release_provenance_check.py"` (bare `python`, matching
`scripts.test`'s existing convention) and change nothing else in the
file — `scripts.test` must stay byte-identical.
